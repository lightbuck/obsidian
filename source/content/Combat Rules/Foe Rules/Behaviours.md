NPCS have behaviours, which if they follow allow their side to gain [[Doom]].

# Behaviour Examples
## Tank Buster
This Character wants to attack the Foe with the highest current Stamina, including conditions that reduce damage.
## Executioner
This Character wants to attack the Foe with the lowest current Health.
## Berserker
This Character wants to attack the last Foe that attacked this Character.
## Brawler
This Character wants to attack the closest Foe.
## Sniper
This Character wants to attack the Foe that's furthest away.
## Assassin
This Character wants to attack the Foe with the lowest Total Health.
## Hunter
This Character wants to attack the same Foe, which it chooses at the beginning of the Combat Scene, and chooses again when that Foe is Knocked Out.
