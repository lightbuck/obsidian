# Experience and Crystals
Experience and Crystals are the two main forms of progression, the first being a meta currency used to acquire new [[Boons]] and learn new [[Techniques]], while the latter is an actual currency used to acquire a number of useful [[Items]] but also [[Armaments]] and their Catalysts and Aspects.
# Character Creation
During character Creation, you choose a Kin for your character to be, this will determine if you have access to any Power from the Hereditary Magics section. 
Then you choose an initial Power. 
Now you have 19 points of Experience to spend according to this table:

| Option                       | EXP Cost |
| ---------------------------- | -------- |
| Power                        | 10       |
| Technique                    | 10       |
| Unique Boon                  | 5        |
| Advanced Boon                | 3        |
| Basic Boon                   | 1+       |
| 5 Skills at Beginner Tier    | 3        |
| Upgrade a skill to Competent | 1        |
Next you have 500 CR to spend according to this table:

| Option             | CR Cost |
| ------------------ | ------- |
| Armament           | 200     |
| Aspect             | 50      |
| Catalyst           | 250     |
| Learning Implement | 25      |
| Consumable         | 5       |
# Character Progression
During play, characters do not have access to the same options as Character Creation to spend EXP on. This table is used instead:

| Option        | EXP Cost |
| ------------- | -------- |
| Unique Boon   | 5        |
| Advanced Boon | 3        |
| Basic Boon    | 1+       |
For a Player Character to learn a new Power, the player needs to organize the event with the GM. Most Powers require specific circumstances and have roleplay and storytelling implications.
Skills are instead practiced and learned during downtime, using Learning Implements.
